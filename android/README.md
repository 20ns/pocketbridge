# PocketBridge Android

Native phone client for your PocketBridge Mac service. Kotlin, Jetpack Compose, Android 16 target API 36. Minimum Android 8 API 26.

## Build

Use Android Studio's bundled JDK 21 and an Android SDK with platform 36. Set `sdk.dir` in untracked `local.properties`, or export `ANDROID_HOME`.

```sh
./gradlew assembleDebug testDebugUnitTest lintDebug
```

Install `app/build/outputs/apk/debug/app-debug.apk` on your Android phone. Open Tailscale on both devices, open the Mac client's pairing screen, then scan the QR using your phone camera or enter its HTTPS address and one-time code in PocketBridge. The app stores its own credential with Android Keystore encryption. It never reads Claude credentials. Android backups are disabled.

Production pairing should use the Mac's private HTTPS Tailscale Serve URL. HTTP is accepted only for localhost, the emulator gateway, and Tailscale addresses where the tunnel encrypts traffic. Redirects are disabled, and credentials are only sent in the authorization header.

## Behaviour

The Mac continues Claude tasks when the phone locks or disconnects. The app receives SSE change notifications while foregrounded (and, with Alerts on, a status-only stream in a foreground service while work runs), coalesces snapshot fetches at 250 milliseconds, and reconciles on every reconnection. Each event refetches only what it changed: streaming text refetches the open chat's messages, and text for other chats refetches nothing. It caches recent chats in preferences and each opened transcript as its own file for offline reading. Prompt drafts use native asynchronous preferences. Unconfirmed delivery UUIDs are committed on an IO thread before any HTTP send, and survive app restarts. Snapshot serialization and disk writes stay off the typing path. If a response is lost, Retry sends the same ID, permission mode, model and effort. HTTP 5xx responses preserve the ID too. HTTP mutations are single-attempt, including 503 Retry-After responses. GET snapshots and streams can recover a stale pooled connection. Mutations open a fresh connection, so idle keepalive sockets cannot spoil the first tap. A definitive 4xx rejection keeps the draft editable. The Mac's durable idempotency ledger prevents duplicate execution. Confirmed deletion commits the cached list, selected chat and delivery-state removal together, serialized with snapshot reconciliation.

Projects open first, with search, Recent/All and sorting. Chats that are working or waiting for an answer anywhere are listed at the top. Select a project to start or reopen one of its chats. There are no back buttons: the Android back gesture returns from a conversation to its project's chats, and the page shrinks with the gesture (predictive back). Only managed chats appear. Project folders are discovered from existing Claude Code session metadata without importing old chats; new folders can be registered in the Mac client. Recent covers the past seven days; All includes older and unused folders. Project lists offer Newest, Oldest and Name sorting; chats offer Newest and Oldest. Chat rows show the last reply as plain text and the model. New chat remains a local draft until the first prompt is sent. Typed drafts and unconfirmed first prompts stay in Recent chats; untouched blank drafts do not. Draft previews use the prompt text. Local unsent drafts can be deleted offline; an unconfirmed delivery remains protected until the Mac resolves it. Long press or the chat menu offers Rename and Delete; active chats must be stopped before deletion. Settings has an on/off switch for Claude Code and Codex, saved on the Mac. New chats start with the last agent used while it is on, otherwise the other one. A chat whose agent is off stays readable and shows "<Agent> is off" with Turn on above the message field.

Screenshots go in with the prompt. The image button opens Android's photo picker (up to eight per message); each image is turned upright, fitted to 2048 px and sent as JPEG 85 to the Mac as soon as it's picked, off the main thread. A failed upload shows Retry on its tile and never blocks typing; Send waits until every image is uploaded, and an image can go alone. Picked images are saved per chat and survive restarts until the Mac accepts the prompt. The upload ids, like the delivery choice below, are saved with the prompt's delivery id before sending, so Retry sends exactly the same images. Prompt images load with the app's credential, are cached on disk under the app's cache folder and decoded at display size; a tap opens a full-screen viewer. Sharing images to PocketBridge from another app opens Send to: a working chat, a recent chat, or a new chat in a recent project.

While a turn runs, typing turns the composer's end into Stop plus a split Steer button. Steer adds the message to the running turn at its next step; its arrow menu also offers Send now, which interrupts the current step and runs the message next. The choice is stored with the delivery id; if the turn already ended, the Mac runs it as a normal turn. Prompts that steered or interrupted are labelled in the transcript. Typing "/" lists the project's commands and skills for the chat's agent, fetched once per ten minutes. A line above the composer shows the branch, lines added and removed, files changed, and ahead or behind; it refreshes when the chat opens, after each turn, on pull to refresh and every 15 seconds while shown. Sub-agents appear in the turn that started them with their model, effort, live time and activity; the working line counts running ones and prefers the agent's own summary of what it is doing. Each finished turn shows how long it worked. A project's chats list offers its Claude Code and Codex sessions from the Mac under "On your Mac"; continuing one forks it, so the original keeps its history, and shows the copied last exchange dimmed under a divider.

With Alerts on (Settings; asked for on the first send), leaving the app while a chat works hands over to a foreground service of the special-use type. It keeps one status-only event stream, fetches state about once a second per burst of changes, backs off on failure and gives up after 15 minutes out of reach. It shows an ongoing Working notification (an Android 16 Live Update where the system supports promoted notifications), "Needs your answer" with Allow and Deny for permission requests, and Done, Failed or Stopped when a turn ends. It stops as soon as nothing runs or waits, when alerts are turned off or the pairing goes, and whenever the app comes back to the screen. Samsung phones may need PocketBridge's battery use set to Unrestricted.

Model, effort and permission mode are pills under the message field. Model opens a panel above the composer, at most half the screen, listing every model the Mac's Claude and Codex CLIs report: current models first, older versions below. An unsent chat can switch agent there; a saved chat keeps its agent. Effort lists only the levels the chosen model supports and hides for models without levels. Changes apply to the next prompt, including while a turn runs, and are saved per chat. New chats start from the last options used with that agent. Bypass permissions is the default. While work runs, the conversation shows the step running now and the elapsed time. Replies that end a turn have a Copy action. When the Mac reports plan usage, Projects shows the limit closest to running out and opens a breakdown per agent with reset times and credits; Settings repeats it, and chats with a reported context, Claude or Codex, show their context window fill beside the title.

Markdown supports paragraphs, headings, nested lists, quotes, rules, bold, italic, links (web addresses only), inline code, fenced code with Copy and lightweight syntax highlighting, diffs with tinted lines, and pipe tables with their column alignment as scrollable grids. Raw HTML stays text. Consecutive tool activity collapses into one "N steps" row; each step expands to its command or input and result. Questions use native radio/checkbox options with a free-text choice, preserve unfinished choices and text across activity recreation, plan approvals render the plan, and permission requests show the full wrapped command before Allow.

A lost connection reconciles automatically and shows a persistent banner with Retry; one-off failures appear as snackbars. Unconfirmed delivery appears below its bubble with Retry. Status uses one vocabulary on both clients: Ready, Working, Needs your answer, Stopping, Interrupted, Failed.

Settings offers Check latest, Download and Install for public GitHub APK releases. Downloads use a separate unauthenticated client, bounded streaming and SHA256 verification. Before Android installation, the APK must match this app's package and signing certificate and have a newer version code. Installation is confirmed by Android; update in place to preserve pairing.

## Checks

Ninety-seven JVM tests cover agent catalogs and option resolution, targeted sync, exact tool-result pairing, the transcript file cache, project search, address boundaries, authorization, SSE cursor and headers, error responses, cancellation, stale GET recovery, single-attempt mutations, disconnect/pair races, persisted prompt ID/text/mode/model/effort/images/delivery, raw image uploads, composer image state and its clearing on acceptance, image downscaling sizes, draft recovery and deduplication, sub-agent placement, turn durations with steers, git labels, "/" filtering, Mac sessions, Send to targets, alert decisions, durable deletion, project activity ordering, bounded GitHub update streams, release selection, tool activity grouping, Markdown parsing, alignment and link safety, the syntax highlighter, model version grouping, and usage labels. `lintDebug` checks Android platform usage. Emulator and real-device findings belong in the root test report; no physical S25 Ultra was attached during development.
