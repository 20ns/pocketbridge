PocketBridge is built and running on this Mac.

Open http://127.0.0.1:8787 for the Mac client. The service starts at login and
keeps the Mac awake on AC power with the lid open. PocketBridge is already
registered as a project. Other folders are discovered from local Claude Code and
Codex chats; use Add folder on the Mac for projects neither has used yet.

ONE-TIME PHONE SETUP
1. Open Tailscale on the Mac, sign in and approve its macOS network extension.
   The phone doesn't need Tailscale or any VPN.
2. Double-click mac/launcher/Setup phone connection.command in this folder.
   It turns on Tailscale Funnel for PocketBridge, saves the address and restarts
   PocketBridge when no chat is working. If it prints a link to allow Funnel or
   HTTPS, open it, approve, and let the helper finish (or rerun it). Only phones
   you pair can use the address. To keep it inside your tailnet instead, run
   mac/scripts/setup-connection.mjs --tailnet-only and use Tailscale on the phone.
3. Download the latest PocketBridge APK from
   https://github.com/20ns/pocketbridge/releases/latest . Install it over the old app.
   The local releases folder also contains PocketBridge-0.4.1.apk.
   Alternatively, open the address from step 2 followed by /PocketBridge.apk
   in Chrome on your phone. Android will ask for the usual APK installation approval.
4. In the Mac client choose Connect phone, then Create pairing code.
5. On the phone enter the address and one-time code in PocketBridge.
   Or scan the QR with the phone camera to prefill them, then tap Connect to Mac.

After pairing, open the app, choose a project and make a chat. Model, effort and
permission mode sit under the message box; tap one to change it. Pick a Claude or
Codex model for a new chat. Bypass permissions is the default. Choices are remembered
per chat, and new chats start from your last ones. Send a prompt, read streamed
text/activity, answer questions and use Stop when needed. Use the back gesture to go back.
The Mac continues a turn while the app is closed. Reopening catches up.

Recent shows recently used project folders; All includes older projects. Search or sort
projects and chats as needed. Empty new chats stay unsaved. Typed drafts remain
in Recent chats on the phone until sent.
Hold a saved chat for Rename or Delete, or use its menu. Stop active work before
deleting. Settings checks for APK updates; Android may ask you to allow
PocketBridge to install apps once. Accept the system update without uninstalling.

Pairing stays saved across app/service restarts. Connect phone on the Mac lists
paired phones; Remove cuts one off at once. Keep Tailscale running on the Mac.
Claude and Codex sign-ins and the Mac's Tailscale key can each require renewal;
disable key expiry for the Mac in Tailscale if desired.

Only chats started through PocketBridge appear. Use its Mac client to continue a
phone chat on the Mac. On this Mac, in the Mac client's sidebar, lists a project's
Terminal, desktop and Codex sessions; picking one continues that same session in
a new chat with its last exchange, so Terminal sees what you send. Other sessions stay untouched. Stop does not undo completed edits. Ready means the turn has ended;
PocketBridge cleans up tools left running in that turn. Concurrent
manual file edits have the usual filesystem conflict risk.

The app runs the official, unmodified Claude Code and Codex CLIs. Each keeps its
own login on the Mac; PocketBridge never extracts subscription tokens or implements
a substitute login. Codex is optional: install it and run `codex login` once.
Provider usage limits and subscription rules still apply. This is a personal CLI
controller, not an Anthropic-approved product or a guarantee against future changes.
Official reference: https://code.claude.com/docs/en/legal-and-compliance

To stop startup, use mac/launcher/Remove startup.command. This keeps your chats.
