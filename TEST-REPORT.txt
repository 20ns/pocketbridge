REPRODUCE
Mac: cd mac && pnpm test
Android: cd android && ./gradlew assembleDebug testDebugUnitTest lintDebug
Signed release: POCKETBRIDGE_SIGNING_KEY="$HOME/.android/debug.keystore" \
  ./gradlew assembleRelease lintRelease
Use Android Studio's JDK 21 and Android SDK platform/build tools 36.

Native recreation check on a paired emulator:
1. Open a pocketbridge://pair link, dismiss the expected Already paired message.
2. adb shell cmd uimode night yes
3. adb shell settings put system font_scale 1.3
4. adb shell uiautomator dump /sdcard/window.xml
5. Inspect the dump: Connected to your Mac; no repeated Already paired message.
For a pending question, choose Something else and type an answer before steps 2-4;
its selected option and text must remain. Restore night no and font_scale 1.0.

DISTRIBUTION AND LIMITS
Private source and signed releases: https://github.com/20ns/pocketbridge
Release assets include their SHA256 file. The same persistent key signs updates;
no credentials, chat database or signing key are stored in source control.
The local release APK is non-debuggable despite retaining the earlier personal
certificate. It is for personal sideloading, not Play Store distribution.

Still awaiting your phone: Tailscale login/VPN approval and private HTTPS transport,
Samsung camera QR handoff, real Wi-Fi roaming and physical-device performance.
Mac logout/FileVault, closed lid and battery-only sleep were not simulated. Keep
this Mac logged in, awake, plugged in and lid open as agreed.
Common Markdown is supported; this parser is not a complete CommonMark engine.
Stop cleans processes in the turn's group; explicitly detached groups are outside
that cleanup. Questions have a 24-hour hook waiting ceiling. Provider authentication,
subscription availability and usage limits remain independent of saved pairing.
